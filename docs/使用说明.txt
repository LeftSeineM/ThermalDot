温度球 1.4.0 · Windows x64 分享版

开始使用
1. 推荐双击「温度球-1.4.0-安装版.exe」，按中文向导安装。
2. 最后一页可选择打开官方 PawnIO 安装向导，用于 CPU 温度读取。驱动需要管理员权限，会留在系统中，可单独卸载。已有组件时跳过此项。
3. 双击桌面「温度球」。启动时会申请管理员权限；同意后可读取更多温度。取消权限提示仍可查看可用的显卡、负载和内存数据。

免安装版
「温度球.exe」是包含 .NET 10 运行环境的独立可执行文件，复制到其他文件夹后可以运行。不需要预装 .NET，也不需要联网启动。
CPU 温度仍依赖兼容的硬件驱动。免安装版没有附带驱动安装文件；右键「CPU 温度读取组件」会打开 PawnIO 官网，由使用者自行决定安装。

操作
单击球球：温度、CPU/GPU 负载、内存、显存和两分钟温度曲线。
详情页右上角「电源 / 电池」：Windows 省电、平衡、性能；支持时可切换电池养护。
电源页「屏幕熄灭时间」（也可右键直达）：分别选择插电和用电池时的时间，点击「应用设置」生效；选「从不」可关闭自动熄屏。提供 1、2、3、5、10、15、20、30、60、120 分钟；系统已有的特殊时长会保留显示。点「重新读取」可放弃尚未应用的选择并载入系统当前值。
这里仅设置无操作多久后熄屏，电脑是否睡眠仍由 Windows 睡眠设置决定。运行任务时如需保持电脑工作，还需检查系统睡眠设置。
按住拖动：移动位置。右键：大小、固定 CPU/GPU、锁定、暂时隐藏、退出、帮助与第三方许可。
暂时隐藏后，可从右下角通知区域（可能在小箭头里）的图标恢复。
没有开机自动启动。重启电脑后需要再次打开。

兼容范围
目标系统：Windows 10 2004 及以上 / Windows 11 的 Intel 或 AMD x64 电脑。此包不支持 ARM Windows、32 位 Windows、macOS。
已实测：ThinkBook 16p G5 IRX / i9-14900HX / RTX 4060 Laptop。
CPU 温度与 GPU 数据由 LibreHardwareMonitor 读取，优先 NVIDIA，其次 AMD，最后 Intel；不同硬件、固件和驱动可能只提供部分读数，未经其他实机验证。
缺失数据显示「—」；它不代表温度或占用为零。CPU 温度缺失时先检查管理员权限、PawnIO 及传感器兼容性。
显存只有在硬件提供可靠容量时才显示；不把共享系统内存混入独立显存。
Windows 电源模式依赖系统支持；选择与实际有效策略不同时会分别显示。此按钮不直接控制原厂 Fn+Q 风扇档位。
电池养护不是所有品牌通用：仅对已经验证过的联想 PowerBattery 组件，并且接口确认支持的设备启用。其他品牌或未知组件版本使用原厂软件。程序不捆绑联想管家，也不分发联想 DLL。
养护上限由固件决定。接口报告支持 80% 时，页面显示约 75%–80% 的目标范围；已有电量高于上限不会主动放电。

数据与隐私
程序不自动联网，不上传硬件信息，不包含广告、账号、自动清理或遥测。
只有主动点击官网入口时才打开浏览器。
设置和最新读数在当前运行账户的 %LOCALAPPDATA%\ThermalDot。分享包中不包含制作者的设备读数、位置偏好或日志。
启动只读取状态。只有主动点击切换按钮才调整电源、充电或屏幕熄灭设置。退出或卸载不会恢复这些系统设置。

卸载
先右键退出球球，在 Windows「已安装的应用」卸载「温度球」。
个人偏好目录保留，可自行删除 %LOCALAPPDATA%\ThermalDot。
PawnIO 是单独的官方系统组件，卸载球球不会移除它；若不再被其他监控软件使用，可在已安装的应用中单独卸载 PawnIO。
免安装版退出后删除 EXE 即可。

转发
日常使用者只需收到安装版 EXE；也可以只发送免安装 EXE。
此版本尚无商业代码签名，Windows 可能显示「未知发布者」。请确认文件来自可信来源；SHA256SUMS.txt 提供本次构建的校验值。
软件尚未经过多机型全面测试，不承诺所有传感器与原厂电池功能都支持。
源码、构建脚本、依赖锁定版本和第三方声明另附。第三方许可也已嵌入程序，可右键查看。
