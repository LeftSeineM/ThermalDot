# 温度球

一个安静的 Windows 桌面悬浮球：随时查看 CPU / GPU 温度、负载、内存和显存，并在兼容的电脑上切换电源与电池养护模式。

没有广告、账户、开机自启或遥测。网络延时检查会产生少量请求，可随时暂停。当前版本 **1.6.0**。

## 下载与安装

前往 [Releases](https://github.com/LeftSeineM/ThermalDot/releases/latest)，下载 **ThermalDot-1.6.0-Setup.exe（安装版）**。普通使用者只需这个文件，无需预装 .NET。

1. 运行安装包，选择安装位置。可安装到 D 盘。
2. 安装完成时，可打开随附的官方 PawnIO 驱动向导；CPU 温度通常需要它。安装由使用者确认，驱动可单独卸载。
3. 从桌面启动温度球，在需要读取 CPU 温度时允许管理员权限。取消权限提示仍可查看可用的 GPU、负载和内存数据。

也提供免安装 EXE：它自带运行环境，但 CPU 驱动仍需另行安装。发行文件尚无商业代码签名，Windows 可能显示“未知发布者”；请确认来源并核对附带的 SHA-256。

## 使用

- 单击圆球：查看温度、资源占用和最近两分钟的温度曲线。
- 右侧蓝色小点：实时上传下载速度，以及 Clash 模式控制、两个美国节点选择和连接延时。
- 按住拖动：移动位置；右键：大小、锁定、选择 CPU / GPU、隐藏或退出。
- 详情页右上角“电源 / 电池”：Windows 省电、平衡、性能，以及可用的电池养护选项。
- 电源页的“屏幕熄灭时间”或右键同名菜单：分别选择插电、用电池时的熄屏时间，点击“应用设置”保存。提供 1–120 分钟常用选项和“从不”，保留系统已有的特殊时长。只调整自动熄屏，不调整睡眠或锁屏设置。
- 隐藏后从通知区域图标恢复。重启电脑后需手动打开。

电源、充电和屏幕设置只在使用者主动点击时修改；程序会读取并显示切换结果。

## 兼容范围

面向 Windows 10 2004 及以上 / Windows 11 的 Intel、AMD x64 电脑。不支持 ARM Windows、32 位 Windows 和 macOS。

温度与资源数据由 LibreHardwareMonitor 读取，不同设备可能只提供部分读数。缺失数据明确显示“—”，不当作零。GPU 优先选择 NVIDIA，其次 AMD，再其次 Intel；未经所有机型实测。

电池养护仅适用于接口确认支持、且已安装受信任版本联想 PowerBattery 组件的电脑。其他品牌和未验证版本请使用原厂软件。程序不捆绑联想管家或联想 DLL。Windows 电源模式不直接控制原厂 Fn+Q 风扇档位。

## 文件与隐私

设置和最新读数保存在当前运行账户的 `%LOCALAPPDATA%\ThermalDot`。本仓库与发行包不含个人配置、设备采样或日志。网速只读取本机接口计数；启用节点延时检查后，每 15 秒通过 Clash 本地 API 向 https://www.gstatic.com/generate_204 发起小请求。暂停状态保存在偏好中。Clash 密钥仅用于本机回环接口认证，不落日志或随包分发。浏览器只在主动点击链接时打开。

详细操作、卸载和兼容性说明见 [使用说明](docs/使用说明.txt)。卸载球球不会自动卸载共享的 PawnIO 驱动，也不会撤销已经选择的系统电源模式。

## 从源码构建

需要 **.NET 10 SDK** 和 **Inno Setup 6.7.3**。本次使用 SDK 10.0.400，发行程序内置运行时 10.0.11。

```powershell
.\Build.ps1 -DotNet 'D:\Tools\dotnet\dotnet.exe' -InnoCompiler 'D:\Tools\Inno Setup\ISCC.exe'
```

缓存默认放在源码目录 `.build-cache`，可用 `-CacheRoot` 指定其他盘的缓存目录。脚本不会安装驱动或启动球球。输出 `publish/ThermalDot.exe` 和 `release/温度球-1.6.0-安装版.exe`。

依赖版本锁定在 `src/packages.lock.json`。运行环境已内嵌，因此发行程序不依赖目标电脑上的 .NET 安装。

## 1.6.0 更新

新增右侧网络小点和网络面板：单主接口网速、Clash 策略组与节点、每 15 秒延时检查、暂停/恢复和立即检查。默认识别当前用户的 Clash for Windows 配置，控制请求只发往回环地址并禁用代理和重定向。支持全局 / 规则 / 关闭，以及两个美国节点选择；切换后读取确认实际状态。未知、直连、拒绝和无唯一节点状态不显示为 VPN 延时。

新增「找回球球（重置位置）」，恢复显示时还原窗口状态并检查屏幕边界。

网络单位采用十进制：1 MB = 1,000,000 B。计数回退、接口切换和休眠间隔会重新采样，避免出现假网速。接口已连接不等同于所有互联网目标都可达；延时失败会显示暂不可用。

## 1.4.0 更新

新增独立的屏幕熄灭时间面板。直接读取当前 Windows 电源计划的插电和电池设置，选择后显式应用并回读确认。读取失败时禁用更改；检测到系统计划或所编辑的值发生变化时要求重新选择。两项保存中途失败会尝试恢复本次写入，并显示重新读取的值。

## 已完成的验证

- 本机 CPU / GPU 温度、资源占用与联想养护状态读取。
- 网络自检覆盖速率单位、计数回退、休眠间隔、回环地址验证、策略组递归、直连/拒绝/循环/负载均衡等状态。
- 屏幕超时读取及面板渲染；自检覆盖 AC/DC 独立修改、“从不”、特殊秒数、过期状态、保存失败恢复和回读不一致。自检不修改本机屏幕设置。
- 移除系统 dotnet 路径后，单文件程序及电池子进程仍可完成只读探测。
- 安装至隔离的临时目录，核对程序与官方驱动安装包 SHA-256 后成功卸载。
- 迁移构建工具与缓存后重新构建，得到与已实测程序相同的 EXE SHA-256。

仍需在其他机型上验证，不保证所有传感器、固件与原厂电池功能都兼容。

## 第三方组件

LibreHardwareMonitor 及其他依赖按各自许可证分发；完整声明和对应源码链接见 [Notices.txt](docs/Notices.txt)，程序右键菜单也能查看。

随附 PawnIO 为未修改的官方签名安装包。它使用自己的许可和安装流程。温度球是独立项目，与 Lenovo、NVIDIA、Microsoft 或 PawnIO 项目没有隶属关系。
代理控制：仅接入当前用户的 Clash for Windows 本地控制接口。TUN 开启时禁用切换；节点列表动态识别，不携带订阅或密钥。切换不强制断开既有连接，新连接按新设置处理。退出温度球保留所选代理设置。
